# 예산서 자동 검토 도구 v1

GitHub + Cloudflare Pages에 올려 사용할 수 있는 정적 웹페이지입니다.

## 사용 방법

1. 이 폴더의 `index.html`, `style.css`, `script.js`, `README.md`를 GitHub 저장소에 업로드합니다.
2. Cloudflare Pages에서 해당 저장소를 연결합니다.
3. Build command는 비워두고, Output directory는 `/` 또는 기본값으로 둡니다.
4. 배포된 페이지에서 파일 2개를 선택한 뒤 `검토 시작`을 누릅니다.

## 입력 파일

### 1. 예산서 작성서식
- `.xlsx`, `.xls`, `.pdf` 지원
- 엑셀 권장
- PDF는 엑셀에서 변환한 텍스트형 PDF 권장
- 스캔본 PDF는 정확히 인식하지 못할 수 있습니다.

### 2. 예산서 / 세출예산명세서
- PDF 권장
- 세출예산명세서의 산출내역과 산출기초를 분석합니다.

## 현재 반영된 1차 검토 기준

1. 퇴직금 적립 현황
   - 작성서식의 적립금 이월액 계에 금액이 있으면 세출예산명세서에 교원퇴직적립금 또는 직원퇴직적립금 편성 여부를 확인합니다.

2. 교직원 보수 검토
   - 교원급여, 교원수당, 직원급여, 직원수당을 비교합니다.
   - PDF의 산출내역과 산출기초가 여러 줄로 표시되어도 하나의 블록으로 묶어 인식하려고 시도합니다.

3. 통합편성 검토
   - 엑셀의 세부 수당들이 PDF에서 하나의 `교원수당` 또는 `직원수당` 등으로 통합 편성된 경우 합산 금액을 비교합니다.

4. 오편성 검토
   - 정상 목에서 찾지 못한 금액이 다른 목에 편성되어 있으면 오편성 의심으로 표시합니다.

5. 금액 허용오차
   - PDF 예산서의 천원 단위 표시, 백원 단위 절사/올림을 고려하여 ±1,000원 및 천원 단위 보정을 허용합니다.

## 보안 안내

- 파일은 서버로 업로드하지 않고 브라우저 안에서만 분석합니다.
- GitHub 저장소는 Private으로 운영하는 것을 권장합니다.
- Cloudflare Access를 연결해 부서 담당자 이메일만 접근 가능하도록 설정하는 것을 권장합니다.
- 민감자료가 포함된 파일은 공용 PC에서 사용하지 않는 것이 좋습니다.

## 한계

- 작성서식마다 표 구조가 크게 다르면 일부 항목이 누락될 수 있습니다.
- 스캔본 PDF는 OCR이 없으므로 정확한 분석이 어렵습니다.
- 1차 버전이므로 실제 파일로 테스트 후 항목명 사전과 파싱 규칙을 계속 보완해야 합니다.
